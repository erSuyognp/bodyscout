BodyScout

A swarm of agents discovers an unknown robot's body from joint commands and a noisy fingertip only, then notices when the body breaks. Judge briefing

All results are MuJoCo simulation, frozen at tag results-final; every number matches results/summary.md. The demo run below was regenerated with the same frozen code.

1 · Provenance DAG, one lane per agent

Every artifact on the blackboard, in the order it was posted. Dashed arrows run from a need to the artifacts that answered it. The red line is the moment the body was secretly damaged; the swarm is not told. Hover a node to trace its ancestry.

2 · Unknown body types: four methods, same budget

The agents are not told what kind of robot they drive. Reach error on unseen targets (log scale, median and min to max over seeds) and the joint structure each one inferred, next to the truth. Same robots, same 64 motion budget, same scorer. Every method that probes one channel at a time finds every structure; only the blind single agent misses. The swarm's own advantage shows up under injected faults (results/summary.md section 5), not here.
